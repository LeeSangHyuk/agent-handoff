# Agent Handoff Project Rules

When working in this repository:

1. Read `HANDOFF.md` before planning substantial work.
2. Treat `HANDOFF.md` as a concise index and current-state summary.
3. Read the files listed under `Relevant Context Files` when they relate to the task.
4. Put durable detail in the relevant `handoffs/*.md` file instead of appending a long log to `HANDOFF.md`.
5. Update `HANDOFF.md` and any relevant theme file before ending meaningful work.
6. Do not store secrets, credentials, or unnecessary private details in handoff files.

Preferred theme files:

- `handoffs/product.md`
- `handoffs/plugin-install.md`
- `handoffs/validation.md`
- `handoffs/roadmap.md`
