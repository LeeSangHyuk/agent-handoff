# Agent Handoff Project Memory

This repository is an MVP for a file-based AI coding session handoff workflow.

Before substantial work:

1. Read `HANDOFF.md`.
2. Use `HANDOFF.md` as the concise current-state index.
3. Read relevant files under `handoffs/` when `HANDOFF.md` points to them.

After meaningful work:

1. Update `HANDOFF.md` with the current focus and next steps.
2. Update the relevant themed file under `handoffs/`.
3. Keep `HANDOFF.md` concise; do not turn it into a chronological session log.

Never store secrets, credentials, or unnecessary private details in handoff files.
